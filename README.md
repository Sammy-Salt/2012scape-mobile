## ✨ About

**2012scape Mobile** is an experimental Android application built to run
the Darkan client on mobile devices.

The project adapts the existing [2009Scape
Mobile](https://github.com/2009scape/2009Scape-mobile) launcher (based
on PojavLauncher), replacing its original game-launch flow with the
infrastructure needed to download, manage, and launch the **Darkan
client --- build 727**.

The goal is a practical mobile experience, with touch-friendly controls
and a launcher that can keep the client up to date.

## 🧭 Project goals

-   📦 Download and manage Darkan client builds.
-   ☕ Integrate the **Java 17+** runtime required by the client.
-   🚀 Launch Darkan from an Android app.
-   🎮 Build toward usable touch and keyboard controls.
-   🔄 Support client updates through the launcher's update flow.
-   ⚙️ Explore improved rendering support as development progresses.

## 🛠️ Development status

2012scape Mobile is a **work in progress**. The Android build pipeline is
established, and launcher/runtime integration is being developed
incrementally.

Rendering compatibility, device testing, and the complete mobile
gameplay experience remain active engineering work. Features listed
above describe project goals; they should not be read as claims that
every feature is already complete.
